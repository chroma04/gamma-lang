# Module `std/hash/sha256`

[All modules](../index.md)

SHA-256 as in FIPS 180-4.

    sha256 :: import "std/hash/sha256"
    d := sha256.sum("abc")                     // a [32]u8: ba7816bf 8f01cfea ...

    s := sha256.init()                         // the same for data in pieces
    s.update("a")
    s.update("bc")
    d2 := s.final()

The state holds one block of input and never allocates. `final` pads and finishes a
copy of the state, so the original can take more data.
