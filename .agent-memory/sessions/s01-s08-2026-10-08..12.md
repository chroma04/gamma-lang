## Lessons that still apply
- python str.replace edits must assert the old text exists (cargo fmt reflows code).
- Commit messages and PRs never mention memory/notes/sessions.
- Check CI after each push (macOS clang rejected `(T){0}` for several pushes unnoticed).
- Push the session branch before spawning worktree agents (they start from the remote).
- gcc may CSE pure recursive calls: don't trust fib as a benchmark.
- macOS qsort_r argument order and qsort comparison order differ from glibc: tests must
  not depend on either.
- gcc's -fstack-clash-protection probes fault before GM_STACK_CHECK runs → SIGSEGV handler.
- Agents that hit usage limits can be resumed with SendMessage; uncommitted work in a
  worktree survives worker restarts.
