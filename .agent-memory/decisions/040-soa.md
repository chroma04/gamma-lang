# 040 Structure-of-arrays `#soa` (s35, 2026-10-23)

User: "get started on your SOA design" (verdict in 039: limited form, arrays + slices).

## Design (spec §5.6.4, §20.2 row, A grammar, C.2 bullet, C.8 rows)
- `#soa [N]S`, `#soa []S`, `#soa []const S`; S concrete struct, not #bits, ≥1 field, no
  field named `len` (it would hide `a.len`). Generic `#soa []T` rejected (like #simd).
- Layout: array = struct of `[N]F` columns; slice = `[^]F` per field then `len: usize`
  (not C-compatible, foreign.rs).
- `a[i]` gathers / `a[i] = s` scatters; `a[i].f` a real place (Index into column);
  `&a[i]` error; `a.f` column (array place or `[]F`); `a.len`; slicing; `^#soa [N]S` →
  `#soa []S` coercion (+ const); construction positional/fill; `for s in a` gathers;
  `is` (slices column-wise content), `@hash` and formatting of slices via a named tuple
  of columns; not ordered; no array methods.
- Allocation: `T.make(n)` (static, like `V.load`) and `s.free()`; one block, columns
  aligned; core `soa_alloc`/`soa_free`/`soa_extent` in lib/core/slice.gm (Debug tag +
  @alloc_check like make/free). Zero size → no allocation, pointers = alignment.

## Implementation (src/sema/soa.rs)
- Each #soa type = compiler-made struct ADT (`AdtId::fresh("#soa [N]S")`), registered in
  Sema.soa (SoaInfo) / soa_types cache; back ends need nothing.
- Hooks: ty_expr Attributed `soa`; expr.rs vector_construction (soa attr), index_value
  (split from index), field() (Index base → soa_element_field, else soa_member), coerce,
  `is`, addr_of (Sema.soa_gathers spans), hash_intrinsic; seq.rs slice_of,
  for_each_value; func.rs assign (scatter); construct.rs construct_struct; methods.rs
  make/free + "no methods"; call.rs build_write (soa_columns_tuple).
- Limits: a #soa slice nested inside another value formats/hashes by its pointers (only
  top-level @write/@hash args are rewritten). `#soa [N]S(...)` at statement start parses
  as an attribute on a declaration (same as #simd; pre-existing).
