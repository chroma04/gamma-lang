# Milestones M0–M12: all done (both back ends). Remaining gaps per area at the end of each.
Spec sections in brackets. Every run test runs on interpreter and C (gcc + clang) and must match.

- M0 bootstrap: crate, CLI, source map, diagnostics, interner, conformance harness, CI.
- M1 front end [§2, App. A]: lexer (newline rules §2.8), parser, `gamma parse --dump` goldens,
  error recovery, no panics on truncated input. Parser ambiguities: decisions/005.
- M2 vertical slice: sema + TIR + interpreter for `gamma run`; literal inference [§6.1].
- M3 data types [§5, §8–§10]: structs/tuples/arrays/slices/pointers/optionals/results/unions,
  match + exhaustiveness (sema/exhaust.rs), conversions, builtin methods, defer/errdefer.
- M4 effects [§12, §13]: handlers (literal + decl), with, clause outcomes, unwinding,
  second-class fns [§11.6], `for` as handler, Yield iterators, cursors [§13.4].
- M5 generics [§16]: decisions/006, 007 (value params, computed array lengths); Alloc,
  List/HashMap in lib/core, @hash, sorts (core/slice: iterative introsort + SymMerge).
- M6 comptime [§17]: when, `target` module (incl. real `target.mode`), #fuel, @static_assert,
  @compile_error, @location, compile-time call stacks, opportunistic + named local consts
  (decisions/024). UB at compile time = interpreter memory checks (alloc id + offset).
- M7 C back end: decisions/008, 012–016, c-backend-plan.md. Gotchas: a Const is a place
  (static gm_cN, `&CONST` must not copy); defers run by a ladder must save/clear gm_unw;
  `(T){}` not `(T){0}`. Stack overflow traps in checked builds (gm_stack_limit TLS, 256 KiB
  reserve); Fast mode overflow = UB. Wide ints >128 bits via runtime gm_w*.
- M8 fibers [§14]: decisions/010, 011 (@stack_size). Static one-shot check sema/cont_check.rs.
  Tests run/fibers.gm, run/fiber_*.gm, check/fibers.gm. Fiber asm: x86-64, aarch64, s390x;
  Windows swaps TIB stack fields; Safe uses ucontext; other archs trap at a switch. Gaps:
  @stack_size not verified against `cc -fstack-usage`.
- M9 modules/tests [§3]: dir modules, imports (relative, std, packages), cycles, `test`
  decls + test handlers (leak-checking alloc, captured output, fake clock, seeded Rand, MemFs,
  MemNet), `gamma test` incl. imported same-package modules, --filter/--all/-j/--coverage.
- M10 interop/low-level [§19, §20]: decisions/009. Threads: std/thread; interp
  src/interp/threads.rs = OS threads + fair ticket GIL (tick() in calls/loops, without_gil()
  around blocking sys ops); C runtime TLS for gm_unw/gm_cur_fiber/fiber pool + gm_rt_lock.
  #callconv (C, Win64; x86-64 only), @asm (forces the C back end: Program::needs_native),
  atomics/fences/volatile. Gaps: const relocs of plain fns stored at effectful fn-pointer
  types; errno-style TLS foreign globals.
- M11 stdlib [§21, §22]: see docs/std.md and lib/std. Pattern for a new OS service:
  tir::SysOp (signature()), interp/sys.rs, gm_rt.c gm_<name> (POSIX + _WIN32), prelude
  handler clause; keep error codes portable (append IoError variants). std/text tables are
  generated by tools/gen_text_tables.py from UCD files (unicode.org blocked by the proxy;
  raw.githubusercontent.com/unicode-org/unicodetools/main/unicodetools/data/ucd/<ver>/
  works). Every addition must clear §22 (decisions/018).
- M12 polish/tooling: #deprecated, #inline/#cold/fast-math hints, §18.3 Debug extras (0xDD
  dead frames, allocation tags via `site = @caller_location()`), native `gamma test`; tooling
  (decisions/023): packages, LSP, editors, release, gamma doc/repl/fmt/bench, Windows port,
  build profiles, ICE reports. Left for the user: tag v0.1.0, publish the VS Code extension.
