A second file of the module. Files are read in name order, so this one comes first.

Shapes and what can be done with them.

A small module for the documentation generator's tests. It uses every kind of public declaration:

shapes :: import "./shapes"
c := shapes.circle(2.0)

Markdown in comments is passed through: emphasis, strong, code and links.
