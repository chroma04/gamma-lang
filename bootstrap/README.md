# Bootstrapping gamma

`seed/` holds `gamma`, the Gamma compiler written in Gamma (`compiler/`), as C: the code
that the compiler generates for its own sources, split into units that share a header
(`gammac.h`), with the runtime in `gammac.rt.c`. With it, `gamma` can be built on a
machine that has a C compiler and nothing else.

```sh
bootstrap/build.sh            # writes target/bootstrap/gamma
```

The script compiles the seed (`gamma0`), has `gamma0` build the compiler of the
current sources (`gamma1`), and has `gamma1` build itself, so that the result is the
current compiler as generated by itself. It takes a few minutes. `CC` selects the C
compiler and `JOBS` the number of units compiled at once. Once `target/bootstrap/gamma`
exists, rebuild after a change with
`GAMMA_STD=$PWD/lib/std GAMMA_RUNTIME=$PWD/runtime target/bootstrap/gamma build compiler -o <out>`.

The seed works on every 64-bit little-endian Unix-like system that Gamma supports: Linux
and macOS on x86-64 and AArch64 (CI builds it on each). The compiler asks the system which
one it runs on, so the C does not depend on the machine it was generated on.

## Where the seed comes from

`seed/SOURCE` names the git trees of `compiler/`, `lib/` and `runtime/` the seed was
generated from. The seed is exactly the C that the compiler of those sources, built by
itself, generates for them; nobody edits it. `bootstrap/verify.sh [GAMMA0]` checks this:
it compiles the seed (or uses the given `gamma0`), has the result generate C for the
named trees and compares. CI runs it on x86-64 Linux, where the seed is generated. So
reviewing the seed means reviewing the Gamma sources it names, and each seed is generated
by the compiler of the one before it.

The seed needs refreshing only when the compiler's sources stop building with it, that
is, when they start using something the seed's compiler does not have.
`tools/refresh-seed.sh [GAMMA]` regenerates it from the committed sources (see
`docs/contributing.md`). The chain of seeds goes back to the last compiler built by the
Rust implementation; see "Retiring the reference" in `docs/self-hosting.md`.
